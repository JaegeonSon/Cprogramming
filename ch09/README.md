
# 실습과제 1. 함수 포인터와 void 포인터 개념 설명

## 1. 함수 선언, 호출, 정의를 각각 설명하라.

- 함수 선언: 함수의 이름, 반환형, 매개변수의 자료형과 개수를 컴파일러에 미리 알려주는 것이다.
- 함수 호출: 선언하거나 정의한 함수를 실행하는 것으로, 함수 이름 뒤에 괄호를 붙이고 필요한 인자를 전달한다.
- 함수 정의: 함수가 실제로 수행할 작업을 작성하는 것으로, 함수의 반환형, 이름, 매개변수 및 실행할 명령문을 작성한다.

## 2. 함수의 자료형은?

함수의 자료형은 함수의 반환형과 매개변수의 자료형 및 개수에 의해 결정된다. 함수의 이름이나 내부에서 수행하는 작업이 달라도 반환형과 매개변수 구성이 같다면 동일한 함수 자료형을 가진다.

예를 들어 `int sum(int a, int b)`의 함수 자료형은 `int(int, int)`이다.

## 3. 함수명의 자료형은?

함수명은 함수가 저장된 메모리의 시작 주소를 나타내며, 주소로 사용할 때 함수 포인터 자료형으로 표현한다.

예를 들어 `int sum(int a, int b)`의 함수 포인터 자료형은 `int (*)(int, int)`이다.

## 4. void 포인터의 용도는?

void 포인터는 가리키는 자료형이 정해져 있지 않은 범용 포인터이다. int, double, char 등 다양한 자료형의 변수 주소를 저장할 수 있다.

여러 자료형의 데이터를 하나의 포인터로 처리하거나 자료형에 관계없이 주소를 전달해야 할 때 사용한다.

## 5. void 포인터에 간접참조 연산을 적용할 때 주의할 점은?

void 포인터는 가리키는 자료형이 정해져 있지 않으므로 해당 주소에서 몇 바이트의 데이터를 읽어야 하는지 알 수 없다.

따라서 직접 간접참조 연산자 `*`를 적용할 수 없으며, 반드시 적절한 자료형의 포인터로 형변환한 후 사용해야 한다.

예를 들어 `*(int*)vp`는 void 포인터를 int 포인터로 형변환한 후 해당 주소의 값을 읽는 표현이다.

## 6. 강제형변환과 자동형변환을 설명하시오.

- 강제형변환: 프로그래머가 형변환 연산자를 사용하여 자료형을 명시적으로 변경하는 것이다.
- 자동형변환: 연산이나 대입 등의 과정에서 컴파일러가 필요한 자료형 변환을 자동으로 수행하는 것이다.

예를 들어 `(double)a / b`는 강제형변환을 사용한 것이고, `double y = a;`에서 정수형 변수 a의 값이 실수형으로 변환되는 것은 자동형변환이다.

# 실습과제 2
## 1. 함수의 매개변수에 함수 포인터를 활용하는 예제
### 코드 설명
- `compute()` 함수는 정수형 변수와 함수 포인터를 매개변수로 받는다.
- `compute(5, display_result)`를 호출하면 숫자 5와 display_result 함수의 주소가 전달된다.
- compute 함수 내부에서는 `num * num`을 계산하고 callback 함수 포인터를 이용하여 display_result 함수를 호출한다.
- display_result 함수는 전달받은 계산 결과인 25를 출력한다.

함수 포인터를 매개변수로 사용하면 외부에서 전달한 함수를 다른 함수 내부에서 실행할 수 있다.

## 2. 함수의 매개변수에 void 포인터를 활용하는 예제
### 코드 설명
- `printValue()` 함수는 void 포인터와 문자형 변수 type을 매개변수로 받는다.
- main 함수에서는 정수형, 실수형, 문자형 변수의 주소를 printValue 함수에 전달한다.
- 함수 내부에서는 type의 값에 따라 자료형을 판단한다.
- void 포인터를 각각 int*, double*, char*로 강제형변환한 후 간접참조 연산자 `*`를 사용하여 실제 값을 출력한다.
