# 실습과제 1

## 1. 스트림과 버퍼의 역할을 각각 설명하시오.

**스트림(Stream)**
- 프로그램과 입출력 장치 사이에서 데이터가 이동할 수 있도록 연결하는 소프트웨어적인 경로이다.
- 입력 스트림은 입력 장치에서 프로그램으로, 출력 스트림은 프로그램에서 출력 장치로 데이터를 전달한다.
- 대표적인 표준 스트림에는 stdin(표준 입력), stdout(표준 출력), stderr(표준 에러)가 있다.

**버퍼(Buffer)**
- 데이터를 입출력하는 과정에서 임시로 저장하는 메모리 공간이다.
- 입력 버퍼는 입력 장치에서 전달된 데이터를 임시 저장하고, 출력 버퍼는 프로그램이 출력할 데이터를 임시 저장한다.
- 데이터를 일정량 모아서 처리함으로써 입출력 효율을 높인다.

## 2. 버퍼를 사용하여 얻는 장점과 단점을 모두 설명하시오.

**장점**
1. 데이터를 모아서 한 번에 전송하므로 입출력 횟수를 줄여 처리 효율을 높일 수 있다.
2. 입출력 장치와 프로그램 사이의 속도 차이를 완화할 수 있다.
3. 키보드 입력 시 엔터키를 누르기 전에 입력 내용을 수정할 수 있다.

**단점**
1. 버퍼에 데이터가 남아 있으면 다음 입력 함수가 의도하지 않은 데이터를 읽을 수 있다.
2. 출력 버퍼에 저장된 데이터가 즉시 화면에 나타나지 않을 수 있다.
3. 데이터를 임시 저장할 추가 메모리 공간이 필요하다.
4. 버퍼의 데이터가 실제로 출력되기 전에 프로그램이 비정상 종료되면 일부 데이터가 손실될 수 있다.

## 3. 입력 버퍼에 데이터가 이미 존재할 때 scanf 함수를 호출한다면 어떤 일이 발생하는가?

- scanf 함수는 새로운 키보드 입력을 기다리지 않고 입력 버퍼에 존재하는 데이터를 읽어온다.
- 읽어온 데이터를 서식 지정자에 따라 변환하여 해당 변수에 저장한다.
- 정상적으로 읽은 데이터는 입력 버퍼에서 제거되지만, 읽지 않은 데이터는 남아 있게 된다.
- 예를 들어 정수를 입력한 후 엔터키('\n')가 남아 있는 상태에서 scanf("%c", &ch)를 실행하면 엔터키가 문자 변수에 저장될 수 있다.

## 4. 운영체제가 어떤 경우에 출력 버퍼의 데이터를 모니터로 출력하는가?

- 출력 버퍼가 가득 찬 경우
- 줄바꿈 문자('\n')가 출력되어 라인 버퍼가 비워지는 경우
- fflush(stdout) 등의 명령으로 버퍼를 명시적으로 비우는 경우
- 프로그램이 정상적으로 종료되면서 출력 버퍼가 비워지는 경우

단, 실제 출력 시점은 표준 출력 스트림의 버퍼링 방식과 실행 환경에 따라 달라질 수 있다.

## 5. scanf 함수와 printf 함수 실행 시 함수와 운영체제의 역할 분담에 대하여 설명하시오.

**scanf 함수**
1. 운영체제는 키보드로부터 입력된 데이터를 표준 입력 스트림으로 전달한다.
2. 입력 데이터는 필요에 따라 입력 버퍼에 저장된다.
3. scanf 함수는 입력 스트림의 데이터를 읽어 서식 지정자에 맞게 변환한다.
4. 변환한 데이터를 지정된 변수에 저장한다.

**printf 함수**
1. printf 함수는 출력할 데이터를 서식 지정자에 맞게 변환한다.
2. 변환된 데이터를 표준 출력 스트림에 전달한다.
3. 출력 버퍼를 사용하는 경우 데이터가 임시로 저장된다.
4. 버퍼링 조건에 따라 데이터가 운영체제를 거쳐 모니터에 출력된다.

**정리**
- scanf : 입력 스트림에서 데이터를 읽어 변수에 저장한다.
- printf : 출력 데이터를 생성하여 출력 스트림에 전달한다.
- 운영체제 : 입출력 장치와 프로그램 사이의 실제 데이터 전달을 지원한다.

# 실습과제 3
## 1. 기존 코드에서 잘못된 결과가 발생하는 이유

기존 코드에서는 scanf("%s", name)을 사용하여 이름을 입력받은 다음 scanf("%c", &blood_type)을 사용하여 혈액형을 입력받는다.

그러나 scanf("%s", name)은 문자열을 읽으면서 입력 마지막의 엔터키('\n')를 입력 버퍼에 남겨둔다.

이후 scanf("%c", &blood_type)이 호출되면 새로운 문자 입력을 기다리지 않고 버퍼에 남아 있는 엔터키를 읽어 blood_type에 저장한다.

따라서 혈액형을 입력하지 못하고 줄바꿈 문자만 출력되는 문제가 발생한다.

## 2. 입력 버퍼의 상태 변화

**① 이름 입력 직후**

사용자 입력 : 홍길동 + 엔터

입력 버퍼:
['홍']['길']['동']['\n']

**② scanf("%s", name) 실행 후**

name = "홍길동"

입력 버퍼:
['\n']

문자열만 읽어 왔으므로 엔터키는 입력 버퍼에 남아 있다.

**③ scanf("%c", &blood_type) 실행 후**

blood_type = '\n'

입력 버퍼:
[비어 있음]

남아 있던 엔터키가 blood_type 변수에 저장되어 새로운 문자 입력 없이 함수가 종료된다.

## 3. 해결 방법

scanf("%c", &blood_type)을 scanf(" %c", &blood_type)으로 수정한다.

서식 지정자 %c 앞에 공백을 추가하면 입력 버퍼에 남아 있는 엔터키, 공백, 탭 등의 공백 문자를 건너뛰고 실제 문자를 읽어온다.

## 4. 수정된 코드의 입력 버퍼 상태

**① 이름 입력 후**

name = "홍길동"

입력 버퍼:
['\n']

**② scanf(" %c", &blood_type) 실행**

기존 엔터키('\n')를 무시하고 새로운 문자 입력을 기다린다.

사용자 입력 : A + 엔터

입력 버퍼:
['A']['\n']

**③ 혈액형 문자 저장 후**

blood_type = 'A'

입력 버퍼:
['\n']

정상적으로 혈액형 'A'가 변수에 저장된다.

# 실습과제 4
## 1. 프로그램 실행 결과가 나타나는 이유

프로그램은 for 반복문을 이용해 총 5번 문자를 입력받고 출력한다.

첫 번째 반복에서 사용자가 "abcde"를 입력하고 엔터키를 누르면 입력 버퍼에는 'a', 'b', 'c', 'd', 'e', '\n'이 저장된다.

scanf("%c", &ch)는 입력 버퍼에서 문자를 한 개씩 읽어오므로 첫 번째 반복에서는 'a'만 변수 ch에 저장된다.

이후 반복에서는 입력 버퍼에 데이터가 이미 존재하기 때문에 추가적인 키보드 입력을 기다리지 않고 'b', 'c', 'd', 'e'를 순서대로 읽는다.

따라서 사용자가 처음에 한 번만 문자열을 입력했음에도 반복문은 5번 실행되며 각 문자를 순서대로 출력한다.

## 2. 반복문 실행 단계별 입력 버퍼 상태

**최초 입력**

사용자 입력 : abcde + 엔터

입력 버퍼:
['a']['b']['c']['d']['e']['\n']

---

**① 첫 번째 반복 (i = 0)**

실행 문장:
scanf("%c", &ch);

읽은 문자 : 'a'

ch = 'a'

입력 버퍼:
['b']['c']['d']['e']['\n']

출력:
문자 입력:abcde
문자: a

---

**② 두 번째 반복 (i = 1)**

읽은 문자 : 'b'

ch = 'b'

입력 버퍼:
['c']['d']['e']['\n']

출력:
문자 입력:문자: b

이미 입력 버퍼에 'b'가 있으므로 새로 입력받지 않고 바로 출력한다.

---

**③ 세 번째 반복 (i = 2)**

읽은 문자 : 'c'

ch = 'c'

입력 버퍼:
['d']['e']['\n']

출력:
문자 입력:문자: c

---

**④ 네 번째 반복 (i = 3)**

읽은 문자 : 'd'

ch = 'd'

입력 버퍼:
['e']['\n']

출력:
문자 입력:문자: d

---

**⑤ 다섯 번째 반복 (i = 4)**

읽은 문자 : 'e'

ch = 'e'

입력 버퍼:
['\n']

출력:
문자 입력:문자: e

---

## 3. 반복문 종료 후 버퍼 상태

for 반복문은 i가 5가 되면 종료된다.

5개의 문자를 모두 읽었으므로 입력 버퍼에는 엔터키('\n')만 남아 있다.

최종 입력 버퍼:
['\n']

## 4. 최종 실행 결과

문자 입력:abcde
문자: a
문자 입력:문자: b
문자 입력:문자: c
문자 입력:문자: d
문자 입력:문자: e

## 5. 결론

scanf("%c", &ch)는 입력 버퍼에서 문자 한 개만 읽어오며, 나머지 문자는 버퍼에 남는다.

입력 버퍼에 읽을 문자가 존재하면 scanf 함수는 새로운 키보드 입력을 기다리지 않고 바로 실행된다.

또한 printf("문자 입력:")에는 줄바꿈 문자가 없기 때문에 두 번째 반복부터는 입력 안내 문구와 출력 결과가 같은 줄에 이어서 나타난다.
