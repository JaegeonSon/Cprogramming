# 실습과제 5. 구조체 배열을 활용한 직원 급여 관리
## 문제 설명
이름, 사번, 급여를 멤버로 가지는 employee 구조체를 정의하시오.

employee 구조체를 이용하여 길이가 4인 구조체 배열을 선언하고, 사용자로부터 직원 4명의 이름, 사번, 급여를 입력받으시오.

입력받은 정보를 바탕으로 다음 기능을 구현하시오.

1. 직원 4명의 정보를 입력받아 구조체 배열에 저장한다.
2. 배열에 저장된 모든 직원의 정보를 순서대로 출력한다.
3. 급여가 가장 높은 직원을 찾아 이름, 사번, 급여를 출력한다.
4. 직원 4명의 급여 합계를 구한 뒤 평균 급여를 소수점 둘째 자리까지 출력한다.

## 구현 조건
- employee 구조체를 반드시 사용할 것
- 구조체 배열을 사용하여 직원 정보를 관리할 것
- 반복문을 사용하여 입력과 출력을 처리할 것
- 조건문을 사용하여 최고 급여 직원을 탐색할 것
- 급여는 정수형으로 저장할 것
- 직원 이름은 공백 없는 문자열로 입력받을 것
