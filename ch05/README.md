# 실습과제 1

## 1. 함수의 인자와 매개변수의 차이를 설명하라.

* 인자(Argument)는 함수를 호출할 때 함수에 전달하는 값이나 변수이다.
* 매개변수(Parameter)는 호출된 함수에서 인자로 전달된 값을 받아 저장하는 변수이다.
* 함수가 호출되면 인자의 값이 매개변수에 전달된다.

---

## 2. 함수가 호출될 때 컴퓨터에 의해 자동으로 실행되는 2가지를 설명하라.

1. 함수의 **매개변수를 위한 메모리 공간이 할당된다.**
2. 할당된 매개변수가 **전달된 인자의 값으로 초기화된다.**

---

## 3. 값에 의한 함수 호출방식의 문제점을 설명하라.

값에 의한 호출은 인자의 값을 매개변수에 **복사해서 전달하는 방식**이다.

따라서 호출한 함수의 변수와 호출된 함수의 매개변수는 서로 다른 변수이므로, 함수 내부에서 매개변수의 값을 변경하더라도 원래 인자의 값은 변경되지 않는다.

즉, **값에 의한 호출방식으로는 다른 함수에서 선언된 지역변수의 값을 직접 변경할 수 없다.**

---

## 4. 주소에 의한 함수 호출방식이 필요한 경우를 설명하라.

주소에 의한 호출은 변수의 값이 아니라 **변수의 주소를 함수에 전달하는 방식**이다.

다른 함수에서 선언된 지역변수의 값을 호출된 함수 내부에서 직접 변경해야 하는 경우 주소에 의한 호출방식이 필요하다.

변수의 주소를 전달하고 포인터를 이용해 해당 주소의 값을 변경하면 원래 변수의 값도 변경할 수 있다.

# 실습과제 2

## 실행 결과가 원하는 대로 나오지 않는 이유

`add2(number)`와 같이 함수를 호출하면 `main` 함수의 `number` 변수 자체가 전달되는 것이 아니라, `number`에 저장된 **값이 매개변수 `value`에 복사되어 전달**된다.

17페이지의 메모리 그림을 기준으로 시간 순서에 따라 설명하면 다음과 같다.

1. **add2 함수 호출 전**

   * `main` 함수의 지역변수 `number`에는 입력받은 값 `15`가 저장되어 있다.
   * 이때 메모리에는 `number = 15`만 존재한다.

2. **add2 함수 호출 및 실행**

   * `add2(number)`가 호출되면 매개변수 `value`를 위한 새로운 메모리 공간이 만들어진다.
   * `number`의 값인 `15`가 `value`에 복사되어 `value = 15`가 된다.
   * 따라서 이 시점에는 `number = 15`, `value = 15`가 각각 별도의 메모리 공간에 존재한다.
   * `value += 2`가 실행되면 `value`의 값만 `15`에서 `17`로 변경된다.
   * `number`와 `value`는 서로 다른 변수이므로 `number`의 값은 여전히 `15`이다.

3. **add2 함수 종료 후**

   * `add2` 함수가 종료되면서 지역변수인 `value`의 메모리 공간은 사라진다.
   * `main` 함수의 `number`는 변경된 적이 없으므로 계속 `15`를 유지한다.

따라서 기존 코드는 **값에 의한 호출(Call by Value)** 방식을 사용하기 때문에 `add2` 함수 내부에서 `value`를 변경해도 `main` 함수의 `number`에는 영향을 주지 않는다.

원하는 결과를 얻으려면 `number`의 **주소를 함수에 전달**하고, 함수에서 포인터를 이용하여 해당 주소의 값을 직접 변경해야 한다.
