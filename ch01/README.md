# 실습과제 1
- 16MB 주소 범위: 0 ~ 16,777,215
- 변수의 주소: 변수가 차지하는 메모리 공간의 시작 번지(가장 작은 주소)
- 변수 주소의 자료형: (변수의 자료형)*
- 포인터: 변수의 주소를 저장하는 변수
- 포인터의 자료형: 포인터가 가리키는 데이터의 자료형에 *를 붙인 자료형
- 주소를 int 변수에 저장: 주소형과 int형의 자료형이 다르므로 직접 저장할 수 없다.

# 실습과제 2
```
double *pt;
```
- pt가 가리키는 데이터 자료형 → double
- pt에 저장되는 주소 자료형 → double*
- pt의 자료형 → double*
- double의 의미 → pt가 가리키는 데이터가 double형이라는 의미
- pt의 메모리 크기 → 32비트: 4Byte / 64비트: 8Byte
