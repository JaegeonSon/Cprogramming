# 실습과제 1

## 1-1. C언어에서 문자를 메모리에 저장하는 방식에 대하여 설명하라. (아스키 코드 참고)

컴퓨터의 메모리에는 문자를 직접 저장하는 것이 아니라 **각 문자에 대응하는 숫자 코드값**을 저장한다.

C언어에서는 일반적으로 문자를 표현할 때 **아스키 코드(ASCII Code)**를 사용한다.
아스키 코드에서는 각각의 문자에 고유한 정수값이 할당되어 있다.

예를 들어 다음과 같다.

| 문자     | 아스키 코드 |
| ------ | -----: |
| `'A'`  |     65 |
| `'B'`  |     66 |
| `'Z'`  |     90 |
| `'a'`  |     97 |
| `'b'`  |     98 |
| `'z'`  |    122 |

따라서 C언어에서 다음과 같이 문자를 저장하면,

```c
char ch = 'A';
```

메모리에는 문자 `A` 자체가 저장되는 것이 아니라 `A`에 해당하는 아스키 코드값인 **65**가 저장된다.

따라서 다음 두 문장은 같은 의미를 가진다.

```c
char ch1 = 'A';
char ch2 = 65;
```

또한 문자형 변수 `char`는 일반적으로 **1바이트의 메모리 공간**을 사용하며, 메모리에는 해당 문자의 코드값이 이진수 형태로 저장된다.

문자열의 경우 여러 개의 문자가 문자형 배열에 순서대로 저장되며, 문자열의 마지막에는 문자열의 끝을 나타내기 위해 **널문자 `'\0'`**가 자동으로 저장된다.

예를 들어,

```c
char str[] = "ABC";
```

는 메모리에 다음과 같이 저장된다.

| 배열 요소    | 저장 문자  | 아스키 코드 |
| -------- | ------ | -----: |
| `str[0]` | `'A'`  |     65 |
| `str[1]` | `'B'`  |     66 |
| `str[2]` | `'C'`  |     67 |
| `str[3]` | `'\0'` |      0 |

따라서 문자열 `"ABC"`를 저장하기 위해서는 실제 문자 3개와 널문자 1개를 포함하여 총 **4바이트의 공간**이 필요하다.

---

## 1-2. 널문자의 용도를 설명하라.

널문자(null character)는 다음과 같이 표현한다.

```c
'\0'
```

널문자의 아스키 코드값은 **0**이며, C언어에서 **문자열의 끝을 표시하기 위해 사용**한다.

C언어에서는 문자열의 길이를 별도의 정보로 함께 저장하지 않기 때문에, 문자열이 어디에서 끝나는지를 판단할 수 있는 방법이 필요하다.

이를 위해 문자열의 마지막 문자 다음에 자동으로 널문자 `'\0'`를 저장한다.

예를 들어,

```c
char str[] = "Hello";
```

는 실제 메모리에 다음과 같이 저장된다.

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

배열 형태로 나타내면 다음과 같다.

```text
str[0] = 'H'
str[1] = 'e'
str[2] = 'l'
str[3] = 'l'
str[4] = 'o'
str[5] = '\0'
```

따라서 실제 문자열의 길이는 5글자이지만 메모리에는 널문자까지 포함하여 총 6개의 문자가 저장된다.

C언어의 문자열 출력 함수인 `printf()`도 `%s`를 사용하여 문자열을 출력할 때 문자들을 처음부터 순서대로 출력하다가 **널문자 `'\0'`를 만나면 문자열이 끝났다고 판단하여 출력을 종료**한다.

```c
printf("%s", str);
```

따라서 널문자의 가장 중요한 용도는 **문자열의 끝을 표시하는 것**이다.

---

## 1-3. 메모리에 저장된 문자열의 끝을 찾는 방법을 설명하라.

C언어에서 문자열의 끝을 찾으려면 문자열의 첫 번째 문자부터 순서대로 확인하면서 **널문자 `'\0'`가 있는 위치를 찾으면 된다.**

예를 들어 다음과 같은 문자열이 있다고 하자.

```c
char str[] = "Hello";
```

메모리에는 다음과 같이 저장된다.

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

문자열의 첫 번째 요소인 `str[0]`부터 하나씩 확인한다.

```text
str[0] → 'H'
str[1] → 'e'
str[2] → 'l'
str[3] → 'l'
str[4] → 'o'
str[5] → '\0'
```

`str[5]`에서 널문자 `'\0'`가 발견되므로 이 위치에서 문자열이 끝났다는 것을 알 수 있다.

이를 C언어 코드로 표현하면 다음과 같다.

```c
int i = 0;

while (str[i] != '\0')
{
    i++;
}
```

위 반복문은 현재 문자가 널문자가 아닌 동안 계속해서 다음 문자를 검사한다.

```c
str[i] != '\0'
```

조건이 거짓이 되는 순간, 즉 `str[i]`가 `'\0'`가 되는 순간 문자열의 끝을 찾은 것이다.

따라서 C언어에서는 **문자열의 첫 번째 문자부터 순서대로 검사하여 널문자 `'\0'`를 만나는 위치를 찾는 방식으로 문자열의 끝을 판단한다.**

---

## 1-4. 문자열의 길이를 구하는 알고리즘을 설명하라.

C언어에서 문자열의 길이는 **문자열의 첫 번째 문자부터 널문자 `'\0'`가 나오기 전까지 존재하는 문자의 개수**를 세어 구할 수 있다.

예를 들어 다음 문자열이 있다고 하자.

```c
char str[] = "Hello";
```

메모리에는 다음과 같이 저장된다.

```text
'H' 'e' 'l' 'l' 'o' '\0'
```

문자열의 첫 번째 문자부터 순서대로 검사하면서 널문자가 나오기 전까지 문자의 개수를 증가시킨다.

```text
'H'  → 1
'e'  → 2
'l'  → 3
'l'  → 4
'o'  → 5
'\0' → 검사 종료
```

따라서 `"Hello"`의 문자열 길이는 **5**가 된다.

알고리즘은 다음과 같다.

```text
1. 문자열의 첫 번째 문자부터 검사를 시작한다.
2. 현재 문자가 널문자('\0')인지 확인한다.
3. 널문자가 아니라면 문자열의 길이를 1 증가시킨다.
4. 다음 문자로 이동한다.
5. 널문자('\0')를 만날 때까지 2~4번 과정을 반복한다.
6. 널문자를 만나면 반복을 종료한다.
7. 지금까지 센 문자의 개수가 문자열의 길이가 된다.
```

이를 C언어 코드로 표현하면 다음과 같다.

```c
int i = 0;

while (str[i] != '\0')
{
    i++;
}

printf("문자열의 길이 : %d\n", i);
```

예를 들어 `str`에 `"Hello"`가 저장되어 있다면 반복문은 `H`, `e`, `l`, `l`, `o` 총 5개의 문자를 검사한 후 `'\0'`에서 종료되므로 `i`의 값은 5가 된다.

따라서 문자열의 길이를 구하는 기본적인 방법은 **문자열을 처음부터 순서대로 탐색하면서 널문자를 만날 때까지 문자의 개수를 세는 것**이다.
