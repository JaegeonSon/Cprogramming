# 실습과제 1

## 1. 주소에 의한 호출을 사용해야 하는 3가지 경우를 설명하라.

### 1-1. 함수에서 다른 함수의 지역변수를 수정하고자 할 때
일반적인 값에 의한 호출은 변수의 값을 복사하여 전달하기 때문에 호출된 함수에서 값을 변경해도 원래 변수에는 영향을 주지 않는다.  
따라서 다른 함수에서 선언된 지역변수의 값을 직접 변경하고자 할 때는 변수의 주소를 전달하는 주소에 의한 호출을 사용해야 한다.

### 1-2. 함수의 매개변수로 배열을 전달할 때
배열을 함수의 인자로 전달할 때는 배열 전체를 복사하는 것이 아니라 배열의 시작 주소인 배열명을 전달한다.  
함수에서는 전달받은 주소를 이용하여 배열의 각 원소에 접근할 수 있다. 따라서 배열을 함수의 매개변수로 전달할 때는 포인터를 이용한 주소에 의한 호출을 사용한다.

### 1-3. 한 함수에서 두 개 이상의 반환값을 만들어내고자 할 때
C언어의 함수는 `return`을 통해 한 번에 하나의 값만 반환할 수 있다.  
두 개 이상의 값을 반환해야 하는 경우에는 값을 저장할 변수들의 주소를 함수에 전달하고, 함수에서 해당 주소를 통해 값을 저장하는 방법을 사용한다.

---

## 2. 최대값을 구하는 알고리즘을 설명하라.

1. 배열의 첫 번째 값을 최대값을 저장할 변수에 저장한다.
2. 배열의 두 번째 원소부터 마지막 원소까지 차례대로 최대값과 비교한다.
3. 현재 원소가 최대값보다 크다면 현재 원소의 값을 새로운 최대값으로 저장한다.
4. 배열의 모든 원소와 비교가 끝나면 최대값 변수에 배열에서 가장 큰 값이 저장된다.

예를 들어 배열이 `50, 20, 30, 40, 10`이라면 처음에는 `50`을 최대값으로 정한다.  
이후 `20`, `30`, `40`, `10`을 차례대로 비교하고 50보다 큰 값이 없으므로 최종 최대값은 `50`이 된다.

---

## 3. const 선언을 사용하는 이유를 설명하시오.

`const`는 변수의 값을 변경할 수 없도록 하여 상수처럼 사용하기 위해 사용하는 선언이다.

프로그램에서 실행 도중 값이 변경되면 안 되는 데이터를 `const`로 선언하면 실수로 값을 변경하는 것을 방지할 수 있다.  
또한 해당 값이 프로그램에서 변경되지 않는 값이라는 것을 코드에서 명확하게 알 수 있기 때문에 코드의 의미를 이해하기 쉬워진다.

예를 들어 세율, 원주율 등과 같이 프로그램 실행 중 값이 변하지 않아야 하는 데이터를 `const`로 선언하여 사용할 수 있다.

따라서 `const`를 사용하면 **값의 불필요한 변경을 방지하고 프로그램을 보다 안전하고 이해하기 쉽게 작성할 수 있다.**

# 실습과제 5
## 문제 1
`ShowAllData` 함수의 목적은 전달받은 배열의 모든 원소를 출력하는 것이다. 따라서 함수 내부에서는 배열의 값을 읽기만 하면 되고 배열의 값을 변경할 필요가 없다.

매개변수 `arr`을 `const int * arr`로 선언하면 포인터를 통해 배열의 값을 읽을 수는 있지만, 배열의 값을 변경할 수는 없다. 즉, `printf("%d ", arr[i]);`와 같이 배열의 값을 참조하는 것은 가능하지만 `arr[i] = 10;`과 같이 값을 변경하려고 하면 컴파일 오류가 발생한다.

따라서 이 함수에서 `const`를 사용한 이유는 함수의 실행 과정에서 실수로 원본 배열의 값이 변경되는 것을 방지하기 위해서이다. 또한 `const` 선언을 통해 이 함수가 전달받은 배열의 값을 변경하지 않고 읽기만 한다는 의도를 명확하게 나타낼 수 있다.
