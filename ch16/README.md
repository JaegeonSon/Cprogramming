# 실습과제 1
## 1. 구조체가 왜 필요한지 설명하시오.
구조체는 서로 다른 자료형의 여러 데이터를 하나로 묶어서 관리하기 위해 필요하다. 예를 들어 학생의 이름, 학번, 성적 등을 하나의 구조체로 묶으면 관련 정보를 효율적으로 저장하고 관리할 수 있다. 또한 프로그램의 가독성이 높아지고 유지보수가 편리해진다.

## 2. 공용체가 왜 필요한지 설명하시오.
공용체는 여러 멤버 변수가 동일한 메모리 공간을 공유하도록 하여 메모리를 효율적으로 사용하기 위해 필요하다. 구조체와 달리 가장 큰 멤버의 크기에 맞춰 메모리를 할당하므로 메모리 공간을 절약할 수 있다. 또한 동일한 데이터를 서로 다른 자료형이나 바이트 단위로 접근하고 해석할 때 유용하다.

## 3. 열거형이 왜 필요한지 설명하시오.
열거형은 서로 관련된 정수 상수들을 의미 있는 이름으로 정의하고 관리하기 위해 필요하다. 숫자를 직접 사용하는 대신 이름이 있는 상수를 사용하면 코드의 의미를 쉽게 이해할 수 있고 가독성이 높아진다. 또한 관련된 상수를 하나의 자료형으로 묶어 관리할 수 있어 프로그램 작성과 유지보수에 유용하다.
