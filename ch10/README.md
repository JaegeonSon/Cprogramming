
# 실습과제 1

## 1. 스트림과 버퍼의 역할을 각각 설명하시오.

**스트림(Stream)**
- 프로그램과 입출력 장치 사이에서 데이터가 이동할 수 있도록 연결하는 소프트웨어적인 경로이다.
- 입력 스트림은 입력 장치에서 프로그램으로, 출력 스트림은 프로그램에서 출력 장치로 데이터를 전달한다.
- 대표적인 표준 스트림에는 stdin(표준 입력), stdout(표준 출력), stderr(표준 에러)가 있다.

**버퍼(Buffer)**
- 데이터를 입출력하는 과정에서 임시로 저장하는 메모리 공간이다.
- 입력 버퍼는 입력 장치에서 전달된 데이터를 임시 저장하고, 출력 버퍼는 프로그램이 출력할 데이터를 임시 저장한다.
- 데이터를 일정량 모아서 처리함으로써 입출력 효율을 높인다.

## 2. 버퍼를 사용하여 얻는 장점과 단점을 모두 설명하시오.

**장점**
1. 데이터를 모아서 한 번에 전송하므로 입출력 횟수를 줄여 처리 효율을 높일 수 있다.
2. 입출력 장치와 프로그램 사이의 속도 차이를 완화할 수 있다.
3. 키보드 입력 시 엔터키를 누르기 전에 입력 내용을 수정할 수 있다.

**단점**
1. 버퍼에 데이터가 남아 있으면 다음 입력 함수가 의도하지 않은 데이터를 읽을 수 있다.
2. 출력 버퍼에 저장된 데이터가 즉시 화면에 나타나지 않을 수 있다.
3. 데이터를 임시 저장할 추가 메모리 공간이 필요하다.
4. 버퍼의 데이터가 실제로 출력되기 전에 프로그램이 비정상 종료되면 일부 데이터가 손실될 수 있다.

## 3. 입력 버퍼에 데이터가 이미 존재할 때 scanf 함수를 호출한다면 어떤 일이 발생하는가?

- scanf 함수는 새로운 키보드 입력을 기다리지 않고 입력 버퍼에 존재하는 데이터를 읽어온다.
- 읽어온 데이터를 서식 지정자에 따라 변환하여 해당 변수에 저장한다.
- 정상적으로 읽은 데이터는 입력 버퍼에서 제거되지만, 읽지 않은 데이터는 남아 있게 된다.
- 예를 들어 정수를 입력한 후 엔터키('\n')가 남아 있는 상태에서 scanf("%c", &ch)를 실행하면 엔터키가 문자 변수에 저장될 수 있다.

## 4. 운영체제가 어떤 경우에 출력 버퍼의 데이터를 모니터로 출력하는가?

- 출력 버퍼가 가득 찬 경우
- 줄바꿈 문자('\n')가 출력되어 라인 버퍼가 비워지는 경우
- fflush(stdout) 등의 명령으로 버퍼를 명시적으로 비우는 경우
- 프로그램이 정상적으로 종료되면서 출력 버퍼가 비워지는 경우

단, 실제 출력 시점은 표준 출력 스트림의 버퍼링 방식과 실행 환경에 따라 달라질 수 있다.

## 5. scanf 함수와 printf 함수 실행 시 함수와 운영체제의 역할 분담에 대하여 설명하시오.

**scanf 함수**
1. 운영체제는 키보드로부터 입력된 데이터를 표준 입력 스트림으로 전달한다.
2. 입력 데이터는 필요에 따라 입력 버퍼에 저장된다.
3. scanf 함수는 입력 스트림의 데이터를 읽어 서식 지정자에 맞게 변환한다.
4. 변환한 데이터를 지정된 변수에 저장한다.

**printf 함수**
1. printf 함수는 출력할 데이터를 서식 지정자에 맞게 변환한다.
2. 변환된 데이터를 표준 출력 스트림에 전달한다.
3. 출력 버퍼를 사용하는 경우 데이터가 임시로 저장된다.
4. 버퍼링 조건에 따라 데이터가 운영체제를 거쳐 모니터에 출력된다.

**정리**
- scanf : 입력 스트림에서 데이터를 읽어 변수에 저장한다.
- printf : 출력 데이터를 생성하여 출력 스트림에 전달한다.
- 운영체제 : 입출력 장치와 프로그램 사이의 실제 데이터 전달을 지원한다.
