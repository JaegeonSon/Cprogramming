
# 실습과제 1
## 1-1. 구조체가 필요한 이유를 설명하라.
구조체는 서로 다른 자료형의 여러 데이터를 하나의 묶음으로 관리하기 위해 필요하다.

예를 들어 학생의 학번(int), 이름(char[]), 학점(double)을 각각 별도의 변수로 관리하는 대신, 하나의 구조체로 묶어서 관리할 수 있다.

이를 통해 데이터의 연관성을 높이고, 코드의 가독성과 유지보수성을 향상시킬 수 있다.

## 1-2. 배열과 구조체의 공통점과 차이점을 설명하라.
### 공통점
- 여러 데이터를 하나의 이름으로 묶어서 관리할 수 있다.
- 메모리에 연속적인 공간을 확보하여 데이터를 저장한다.
- 중괄호 `{}`를 사용하여 초기화할 수 있다.

### 차이점
- 배열은 같은 자료형의 데이터만 저장할 수 있지만, 구조체는 서로 다른 자료형의 데이터를 저장할 수 있다.
- 배열은 인덱스([])로 요소에 접근하지만, 구조체는 점 연산자(.)로 멤버에 접근한다.
- 배열은 동일한 종류의 데이터를 여러 개 저장할 때 적합하고, 구조체는 서로 연관된 다양한 데이터를 묶을 때 적합하다.

## 1-3. 기본자료형과 구조체의 차이를 설명하라.
기본자료형은 C언어에서 기본적으로 제공하는 int, char, float, double 등의 자료형으로, 하나의 값을 저장하는 데 사용한다.

반면 구조체는 사용자가 여러 자료형을 조합하여 직접 정의하는 사용자 정의 자료형으로, 서로 관련된 여러 값을 하나의 변수에 저장할 수 있다.

즉, 기본자료형은 개별 데이터를 저장하는 자료형이고, 구조체는 여러 데이터를 하나로 묶어서 관리하는 자료형이다.

## 1-4. 구조체 정의와 구조체 변수 선언의 의미를 각각 설명하라.
### 구조체 정의
구조체의 이름과 내부 멤버 변수들의 자료형 및 구성을 정하는 것이다.

구조체를 정의하는 것만으로는 실제 데이터를 저장할 구조체 변수의 메모리 공간이 할당되지 않는다.

```c
struct student {
    int number;
    char name[20];
    double grade;
};
```

### 구조체 변수 선언
정의된 구조체 자료형을 이용하여 실제 데이터를 저장할 변수를 만드는 것이다.

변수를 선언하면 해당 구조체의 멤버들을 저장할 메모리 공간이 확보된다.

```c
struct student s1;
```

위 코드에서 `struct student`는 구조체 자료형이고, `s1`은 선언된 구조체 변수이다.
